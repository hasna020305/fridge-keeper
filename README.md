# 🌿 Fridge Keeper

식품의 유통기한을 확인하고 관리하는 웹 프로그램입니다.

## 프로젝트 목적

보관 중인 식품과 유통기한을 한눈에 확인하여
식품을 잊고 방치하는 일을 줄이고,
유통기한이 가까운 식품부터 사용할 수 있도록 돕습니다.

## 주요 기능

- 식품 이름, 유통기한, 수량, 보관 장소 등록
- 식품 목록 표시 및 삭제 확인
- 식품 이름 검색
- 등록순, 유통기한순, 식품 이름순 정렬
- 유통기한까지 남은 날짜 계산
- 오늘부터 3일 이내인 식품과 기한이 지난 식품 색상 구분
- localStorage를 활용한 데이터 저장 및 불러오기

## 사용 기술 및 개발 도구

- HTML: 화면 구조
- CSS: 연두색 테마와 화면 디자인
- JavaScript: 기능 구현
- localStorage: 브라우저에 식품 데이터 저장
- VS Code: 코드 작성
- Live Server: 로컬 실행
- Git: 소스 코드 버전 관리
- GitHub: 코드와 변경 이력 보관
- ChatGPT: 개발 안내, 코드 설명 및 오류 해결 지원

## 파일 구성

| 파일 | 역할 |
|---|---|
| index.html | 식품 입력 양식, 검색·정렬 메뉴, 목록 |
| style.css | 화면 디자인과 기한별 색상 |
| script.js | 추가·삭제·검색·정렬·날짜 계산·저장 |
| README.md | 프로젝트 소개와 실행 방법 |

## 실행 방법

1. 저장소를 클론하거나 ZIP으로 내려받습니다.
2. VS Code에서 프로젝트 폴더를 엽니다.
3. Live Server 확장을 설치합니다.
4. index.html을 오른쪽 클릭합니다.
5. Open with Live Server를 선택합니다.
6. 브라우저에서 프로그램을 사용합니다.

## 데이터 저장 방식 및 한계

식품 목록은 같은 브라우저의 같은 실행 주소에 저장됩니다.
새로고침하거나 탭을 닫았다 다시 열어도 목록이 유지됩니다.

브라우저의 사이트 데이터를 삭제하면 목록이 사라질 수 있습니다.
다른 컴퓨터나 브라우저와 데이터가 자동으로 공유되지는 않습니다.
입력한 식품 목록은 GitHub에 업로드되지 않습니다.

남은 날짜는 컴퓨터의 날짜를 기준으로 계산하며,
화면을 새로고침할 때 갱신됩니다.
날짜 표시는 식품의 실제 안전성을 판단하는 기능은 아닙니다.

## 버전 관리

기본 화면, 식품 추가, 삭제, 저장, 날짜 표시, 검색, 정렬 등
개발 단계별로 커밋하고 GitHub에 업로드하여 변경 이력을 관리합니다.

## 향후 개선 계획

- 등록한 식품 정보 수정
- 보관 장소별 필터
- 유통기한 알림
- 보관 식품으로 활용할 수 있는 요리법 소개
